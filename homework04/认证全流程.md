【注册】
客户端                      服务端                       数据库
│ POST /auth/register       │                            │
│ {username,password,email} │                            │
├──────────────────────────►│                            │
│                     ① 校验参数（binding tag）           │
│                     ② 查重（用户名/邮箱） ──────────────►│
│                     ③ bcrypt.GenerateFromPassword()    │
│                        · 自动加随机盐                   │
│                        · 10 轮计算，故意很慢           │
│                     ④ INSERT INTO users ──────────────►│
│ ◄──────────────────201 {id,username,email}             │
│
【登录】
│ POST /auth/login          │
│ {username,password}       │
├──────────────────────────►│
│                     ① SELECT * FROM users WHERE username=?
│                     ② bcrypt.CompareHashAndPassword()
│                     ③ 用 JWT_SECRET 签发令牌
│ ◄──200 {token,user}       │
│
【访问受保护接口】
│ POST /posts               │
│ Header: Authorization: Bearer <token>
├──────────────────────────►│
│                     JWTAuth 中间件:
│                       ① 拆出 token
│                       ② 验签（用同一个 SECRET）
│                       ③ 检查 exp 是否过期
│                       ④ c.Set("current_user_id", 1)
│                           └─ c.Next() 传给业务 Handler
│ ◄──201 创建成功            │
